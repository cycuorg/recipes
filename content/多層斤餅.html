多層斤餅

<< Previous: 捲餅

多層燙麵／半燙麵斤餅，主要是利用熱水燙麵與冷水和麵的比例，搭配油酥、抹油及反覆摺疊擀製，製作出外層酥香、內層柔軟，而且具有多層次口感的斤餅。

如果是要做餐廳或麵食店使用的斤餅，建議先掌握「半燙麵」與「全燙麵」兩種做法，再比較成品差異。

一、斤餅的兩種麵糰配方

1. 半燙麵斤餅（推薦）

半燙麵是將一部分麵粉用熱水燙熟，另一部分用冷水揉合。

優點：

  • 麵糰柔軟、有韌性。
  • 擀製時不容易破皮。
  • 層次明顯，內部柔軟。
  • 放涼後仍保有一定柔軟度。
  • 適合做多層斤餅及蔥抓餅類產品。

半燙麵材料比例

以下以中筋麵粉 1000 克為基準：

材料 重量 麵粉百分比
中筋麵粉 1000克 100%
95°C熱水 350克 35%
常溫冷水 250克 25%
鹽 10克 1%
沙拉油 20克 2%

總加水率60%熱水與冷水比例：

  • 熱水：350克
  • 冷水：250克
  • 熱水占總水量約58.3%
  • 冷水占總水量約41.7%

這個比例適合製作有韌性、又能做出層次的斤餅。

2. 全燙麵斤餅

全燙麵是全部使用熱水與麵粉混合，使麵粉中的澱粉部分糊化。

材料 重量
中筋麵粉 1000克
90～95°C熱水 550～600克
鹽 10克
沙拉油 20克

特性：

  • 麵糰非常柔軟。
  • 延展性好。
  • 成品比較軟，不太有嚼勁。
  • 冷卻後容易偏硬或失去彈性。
  • 適合柔軟型燙麵餅，但不一定適合追求酥脆、分明層次的斤餅。

我的建議：若目標是傳統餐廳多層斤餅，優先採用半燙麵。

二、多層斤餅的油酥配方

斤餅的層次，除了麵糰之外，最重要的就是油酥。

油酥的作用是讓麵皮之間形成油脂隔離層，煎熟後就會產生一層一層的口感。

油酥材料（麵粉1000克配方）

材料 重量
中筋麵粉 100克
沙拉油 150克
豬油 50克
鹽 8克
五香粉 2克（可不加）
白胡椒粉 1克（可不加）

油酥製作方法

  1. 沙拉油與豬油加熱至約120～140°C。
  2. 將熱油倒入麵粉中。
  3. 一邊倒油，一邊攪拌。
  4. 加入鹽、五香粉及白胡椒粉。
  5. 攪拌成均勻、可以塗抹的糊狀。
  6. 放涼備用。

注意：油酥不能太稀，否則容易流出；也不能太乾，否則擀製時容易破壞層次。

如果希望成品較清爽，可以全部使用沙拉油；如果希望香氣濃郁，則可提高豬油比例。

三、多層斤餅詳細製作程序

以下以半燙麵1000克麵粉的配方示範。

第一步：熱水燙麵

  1. 將1000克麵粉放入攪拌盆。
  2. 先取350克熱水，水溫約95°C。
  3. 熱水分次倒入麵粉。
  4. 用筷子快速攪拌。
  5. 讓麵粉形成大小不一的絮狀物。
  6. 不需要全部攪拌成團。

這個步驟的重點是讓部分麵粉糊化，降低麵糰的筋性。

第二步：加入冷水揉麵

  1. 等燙麵稍微降溫。
  2. 加入250克常溫水。
  3. 加入10克鹽。
  4. 開始攪拌。
  5. 再加入20克沙拉油。
  6. 揉成完整麵糰。

揉麵時間：

  • 手揉：約12～15分鐘。
  • 攪拌機：約8～10分鐘，依機器及速度調整。

麵糰完成標準：

  • 表面光滑。
  • 不黏手。
  • 有延展性。
  • 拉開時不會立即斷裂。

第三步：第一次醒麵

將麵糰放入盆中，表面稍微抹油，蓋上保鮮膜。

醒麵時間：

  • 室溫25～28°C：約30～40分鐘。
  • 冬天較冷時：約40～60分鐘。

醒麵的目的，是讓麵筋放鬆，後續擀製比較容易。

第四步：分割麵糰

將麵糰分成每個250～300克。

建議：

單個重量 成品大小
200克 小型斤餅
250克 中型斤餅
300克 大型斤餅
350克 厚實大型斤餅

分割後滾圓，表面抹少許油，再醒麵15～20分鐘。

第五步：擀開及塗抹油酥

烙饼时 直接烙是大错特错 多加这一步 饼柔软起层 凉了也不硬 ＊ 阿波罗新闻网

  1. 取一個麵糰。
  2. 桌面抹少量油。
  3. 將麵糰擀成長方形薄片。
  4. 厚度約1.5～2毫米。
  5. 均勻塗抹油酥。
  6. 四周保留約1公分，不要塗太滿。

油酥用量：

每個250克麵糰，約使用35～45克油酥。

第六步：摺疊製作多層結構

這個步驟是斤餅層次的關鍵。

方法A：扇形摺疊法（推薦）

  1. 將塗好油酥的長方形麵皮像摺扇子一樣，來回摺疊。
  2. 摺成長條狀。
  3. 將長條輕輕拉長。
  4. 從一端開始捲起。
  5. 捲成圓形螺旋狀。
  6. 將尾端壓在底部。
  7. 靜置15～20分鐘。

這樣就能形成多層結構。

方法B：三折法

  1. 麵皮擀成長方形。
  2. 塗抹油酥。
  3. 左側往中間摺。
  4. 右側再往中間摺。
  5. 再次擀開。
  6. 重複一次三折。
  7. 最後捲成圓形。

這種方式也能形成層次，但摺疊次數和擀製力道要控制好，避免把油酥擠出來。

第七步：最後擀製

  1. 將捲好的麵糰放置15分鐘。
  2. 用擀麵棍從中心向外擀。
  3. 擀成直徑約22～26公分。
  4. 厚度約3～5毫米。
  5. 力道要均勻。
  6. 不要過度擀壓，否則容易破壞層次。

第八步：煎製斤餅

建議使用平底鍋或鐵板。

煎製程序：

  1. 平底鍋預熱至約160～180°C。
  2. 鍋面刷薄薄一層油。
  3. 放入斤餅。
  4. 中小火煎約2～3分鐘。
  5. 底面呈金黃色後翻面。
  6. 另一面再煎約2～3分鐘。
  7. 視餅的厚度調整時間。
  8. 煎至兩面金黃、內部熟透。

最後可以用鍋鏟輕輕拍打餅面，幫助層次鬆開。

四、半燙麵與全燙麵成品差異

比較項目 半燙麵 全燙麵
麵糰筋性 中等 低
延展性 好 很好
操作性 好 較黏軟
層次表現 明顯 較不明顯
外層口感 酥香 柔軟
內部口感 柔韌 軟糯
冷卻後口感 較佳 容易變硬
適合用途 多層斤餅 柔軟燙麵餅

五、製作多層斤餅最重要的五個技術

  1. 熱水溫度： 建議95°C左右，讓部分麵粉充分燙熟。
  2. 加水比例： 半燙麵總水量約60%，可依麵粉吸水性調整。
  3. 醒麵時間： 一定要充分醒麵，否則擀製容易回縮。
  4. 油酥厚薄： 必須均勻，不宜過厚或過薄。
  5. 摺疊方式： 扇形摺疊後捲成螺旋，是製作多層斤餅很實用的方法。

以下分別提供以中筋麵粉1000克為基準的配方，包含材料比例、製作程序、火候及商用操作重點。

A. 北京烤鴨薄斤餅

一、成品特色

北京烤鴨薄斤餅與一般多層酥餅最大的差別是：

  1. 不需要油酥。
  2. 不需要大量摺疊。
  3. 主要依靠麵筋延展性形成柔軟薄皮。
  4. 透過兩片麵皮中間抹油、疊合擀製，再分開形成薄餅。
  5. 蒸熟後應該柔軟、富有彈性，而且可以輕鬆剝開。

這種做法也稱為雙片合擀法。

二、材料比例

推薦配方：半燙麵版本以中筋麵粉1000克計算：

材料 重量 麵粉百分比
中筋麵粉 1000克 100%
90～95°C熱水 300克 30%
常溫水 280克 28%
鹽 8克 0.8%
沙拉油 10克 1%

總加水量580克，總加水率58%。

這個比例的特點是：

  • 有一定筋性。
  • 麵皮延展性佳。
  • 擀薄時不容易破裂。
  • 蒸熟後柔軟有彈性。

水量可以視麵粉吸水性增減20～30克。

三、製作程序

步驟1：熱水燙麵

  1. 中筋麵粉1000克放入攪拌盆。
  2. 將300克熱水加熱至90～95°C。
  3. 分次倒入麵粉。
  4. 一邊倒水，一邊使用筷子攪拌。
  5. 讓麵粉形成均勻的雪花狀。
  6. 靜置約5～10分鐘，讓溫度稍微下降。

注意：不要將所有麵粉都燙成黏稠的麵糊，保留部分麵粉的筋性，有助於後續擀薄。

步驟2：加入冷水及揉麵

  1. 加入280克常溫水。
  2. 加入8克鹽。
  3. 開始揉麵。
  4. 麵糰大致成形後加入10克沙拉油。
  5. 持續揉至表面光滑。

揉麵時間：

  • 手揉約12～15分鐘。
  • 攪拌機約8～10分鐘，視機器調整。

完成的麵糰應該柔軟、光滑，具有延展性。

步驟3：醒麵

將麵糰蓋好，避免表面乾燥。

  • 第一次醒麵：30分鐘。
  • 分割滾圓後：再醒麵15～20分鐘。

醒麵非常重要。

如果醒麵不足，麵糰會產生回縮現象，擀出來的餅容易厚薄不均。

步驟4：分割麵糰

建議每個麵糰分割為：

每個麵糰重量 適合尺寸
20克 小型薄餅
25克 標準薄餅
30克 稍大薄餅

如果是餐廳搭配烤鴨使用，我建議先以每個25克測試。

將分割好的麵糰滾圓，表面抹少許油，再醒麵10～15分鐘。

步驟5：雙片合擀法

這是北京烤鴨薄斤餅最重要的技術。

  1. 取兩個25克小麵糰。
  2. 分別壓成小圓餅。
  3. 在其中一片表面刷薄薄一層沙拉油。
  4. 將另一片疊在上面。
  5. 用手輕壓，使兩片麵皮貼合。
  6. 用擀麵棍從中心向外擀。
  7. 不斷轉動麵皮，使其均勻變薄。
  8. 最後擀成直徑約16～18公分的圓形。

注意：

  • 中間的油不能太少，否則蒸熟後不好剝開。
  • 也不能太多，否則容易滑動、厚薄不均。
  • 兩片麵皮邊緣必須對齊。

步驟6：蒸製

建議使用蒸籠。

  1. 蒸籠水先煮滾。
  2. 將擀好的雙片麵皮放入蒸籠。
  3. 大火蒸約3～4分鐘。
  4. 麵皮熟透後取出。
  5. 稍微放涼。
  6. 沿著邊緣將兩片分開。

如果一次蒸製很多片，建議每一片都要適當撒粉或使用防沾墊紙，避免生麵皮互相黏住。

步驟7：成品保存

  • 蒸熟後趁溫熱分開。
  • 用乾淨布或保鮮膜覆蓋，避免乾燥。
  • 短時間供餐可保溫保存。
  • 冷藏保存時應密封，使用前重新蒸熱。
  • 不建議長時間暴露在室溫下。

四、北京烤鴨薄斤餅的品質標準

理想成品

  • 顏色：乳白色。
  • 厚度：均勻、薄透。
  • 口感：柔軟、略帶Q度。
  • 延展性：包烤鴨時不易破裂。
  • 剝離性：兩片容易分開，不會黏成一團。

B. 傳統多層酥香斤餅

這種斤餅與北京烤鴨薄餅完全不同。

它的核心在於：

  • 半燙麵製作柔軟麵糰。
  • 使用油酥隔離麵皮。
  • 透過摺疊產生多層結構。
  • 利用豬油或沙拉油增加酥香。
  • 透過煎製形成外酥內軟的口感。

一、材料比例

以中筋麵粉1000克為基準。

1. 主麵糰配方

這個比例比較適合多層斤餅，因為麵糰不會太硬，也保留一定筋性。

2. 油酥配方

中筋麵粉 120克
沙拉油 150克
豬油 50克
鹽 10克
五香粉 2克
白胡椒粉 1克

這份油酥可以做出明顯油酥香氣。

如果不喜歡五香味，可以將五香粉及白胡椒粉省略。

二、製作程序

步驟1：熱水燙麵

  1. 1000克中筋麵粉放入攪拌盆。
  2. 350克熱水加熱至95°C左右。
  3. 分次倒入麵粉。
  4. 使用筷子攪拌成雪花狀。
  5. 靜置5～10分鐘。

這個步驟讓部分麵粉糊化，降低麵糰筋性，使成品較柔軟。

步驟2：加入冷水揉麵

  1. 加入250克常溫水。
  2. 加入10克鹽。
  3. 攪拌至麵糰形成。
  4. 加入20克沙拉油。
  5. 揉至表面光滑。

揉好的麵糰應該是柔軟、不黏手、可以延展的狀態。

步驟3：第一次醒麵

將麵糰放在盆內，表面抹少量油。

蓋上保鮮膜。

醒麵30～40分鐘。

步驟4：製作油酥

  1. 將150克沙拉油及50克豬油放入鍋內。
  2. 加熱至約120～140°C。
  3. 將120克麵粉放入耐熱容器。
  4. 將熱油慢慢倒入麵粉。
  5. 一邊倒，一邊攪拌。
  6. 加入10克鹽。
  7. 加入五香粉及白胡椒粉。
  8. 攪拌成細緻油酥。
  9. 放涼備用。

油酥應該呈現可以均勻塗抹的膏狀。

如果太稀，可增加少量麵粉；如果太乾，可補少量油脂。

步驟5：分割麵糰

建議每個麵糰重量：

重量 用途
200克 小型斤餅

建議先以250克為標準。

分割滾圓後，醒麵15～20分鐘。

步驟6：擀開麵糰

  1. 桌面抹少量油。
  2. 將麵糰壓平。
  3. 使用擀麵棍擀開。
  4. 擀成長方形。
  5. 厚度約1.5～2毫米。
  6. 表面均勻塗抹油酥。

每個250克麵糰建議使用35～45克油酥。

四周保留約1公分，避免油酥在摺疊時大量擠出。

步驟7：扇形摺疊法

這是我最推薦的多層斤餅製作方式。

  1. 將塗好油酥的長方形麵皮放平。
  2. 從一端開始，像摺扇子一樣來回摺疊。
  3. 每一摺約2～3公分寬。
  4. 摺成長條。
  5. 輕輕拉長，但不要拉破。
  6. 從一端開始捲成螺旋圓形。
  7. 將尾端壓在底部。
  8. 靜置15～20分鐘。

這種方式可以使麵皮形成多層油酥結構。

步驟8：第二次擀製

  1. 將螺旋狀麵糰翻面。
  2. 用手掌輕壓。
  3. 從中心向外擀開。
  4. 擀成直徑22～26公分。
  5. 厚度約3～5毫米。
  6. 擀製時力道要均勻。

切記不要太用力。

如果將麵糰擀得太薄，容易使油酥層破裂，層次會不明顯。

步驟9：煎製

煎製是決定酥香口感的關鍵。

  1. 平底鍋預熱。
  2. 鍋面刷少量油。
  3. 放入斤餅。
  4. 使用中小火煎製。
  5. 約2～3分鐘翻面。
  6. 另一面再煎約2～3分鐘。
  7. 兩面呈現金黃色即可。
  8. 出鍋後用手或鍋鏟輕拍餅面，使層次鬆開。

建議鍋面溫度約160～180°C，並依餅的厚度調整火力及時間。

三、多層斤餅的三種油酥比例

油酥的比例會直接影響成品的酥脆度。

以下是以每個250克麵糰為基準：

口感目標 油酥用量 特性
柔軟型 25～30克 油脂較少、內部柔軟
酥香型 35～45克 層次明顯、外酥內軟
濃酥型 50～55克 油香濃郁、較酥脆

我最推薦35～45克。

四、如何讓斤餅真正一層一層撕開？

這裡有幾個技術重點：

1. 油酥要均勻

油酥塗抹不均，會造成有些地方黏在一起，有些地方層次太油。

2. 摺疊不能太緊

扇形摺疊時不要過度壓實，否則層與層之間容易黏合。

3. 醒麵不能省略

摺疊後靜置15～20分鐘，讓麵筋放鬆，擀製時比較不會破壞層次。

4. 煎製不能使用太大火

火力太大，外面很快焦黑，內部卻還沒熟透。

5. 出鍋後輕拍

利用輕拍讓煎熟的麵皮層次鬆開。
